# CAD 도면 활용

## 결론 — CAD는 위치추정 맵으로 쓰지 않는다

| 용도 | 가능 |
|---|---|
| CAD를 그대로 Nav2 맵으로 | **비권장** |
| SLAM 맵의 정답지(ground truth) | 권장 |
| 유리벽·거울 구간 보정 | 권장 |
| 금지구역 마스킹 | 권장 |
| 웨이포인트 좌표 추출 | 권장 |
| 주행 경로 사전 설계 | 권장 |

### 근거

BIM/CAD 기반 위치추정을 실측 사무실에서 비교한 연구에서, 중간 수준의
Scan-BIM 편차가 있는 환경에서 AMCL의 병진 RMSE는 빈 환경 8.5cm에서
실제 환경 **33.7cm로 네 배 악화**되었습니다. 반면 포즈그래프 기반
방식(Cartographer, SLAM Toolbox)은 같은 조건에서 **7.2cm**를 유지했습니다.
(arXiv:2308.05443)

**라이다가 보는 세계 ≠ CAD가 그리는 세계**

| CAD | 라이다 |
|---|---|
| 벽 중심선 | 벽 표면 |
| 설계 위치 | 시공 오차 |
| — | 책상, 파티션, 캐비닛, 화분 |
| 창문=벽 | 유리 투과/난반사 |
| 전 층 정보 혼재 | 라이다 높이의 단면만 |

특히 이 구성은 높이 밴드가 `[0.05, 0.60]`이라 **책상 다리와 파티션 하단이
지배적**입니다. CAD에는 이것들이 없습니다.

## 실용적 활용

### 1. SLAM 맵과 CAD 대조 (드리프트 정량 측정)

```bash
pip3 install --user ezdxf matplotlib numpy pillow pyyaml
```

**① 레이어·단위 확인** → **② 벽만 렌더링** → **③ 대응점 5~8쌍 수집**
(RViz `Publish Point` + CAD 좌표) → **④ 유사변환 추정 및 RMSE 산출**

| RMSE | 판정 |
|---|---|
| 0.10m 미만 | 우수 |
| 0.10~0.25m | 양호 (자율주행 충분) |
| 0.25~0.50m | 특정 구역 드리프트. 그 구역 재매핑 |
| 0.50m 초과 | 루프 폐합 실패. 재매핑 |

겹쳐본 이미지에서 **어느 구역이 얼마나 어긋났는지 한눈에** 보입니다.
이것이 맵 품질 평가의 가장 강력한 도구입니다.

### 2. 유리벽·금지구역 정확히 그려넣기

라이다는 유리를 투과하거나 난반사하여 맵에 구멍이 생깁니다.
CAD에는 유리벽이 정확한 좌표로 있으므로, 정렬된 변환으로
SLAM 맵에 직접 벽을 그려넣을 수 있습니다.

계단·낭떠러지도 같은 방법으로 두껍게 막으세요.
Foxy에는 Keepout Filter가 없으므로 이것이 유일한 방법입니다.

### 3. 웨이포인트 좌표 추출

CAD에서 "회의실A 중앙" 좌표를 읽어 SLAM 좌표로 변환.
단 **±30cm 오차**가 있으므로 실제로 가보고 미세조정하거나,
최종적으로는 `waypoint_tool save`로 실측 등록하는 것이 정확합니다.

### 4. 주행 경로 사전 설계

CAD 도면을 인쇄해 매핑 루트를 미리 그려두세요.
현장에서 즉흥적으로 도는 것보다 훨씬 좋은 맵이 나옵니다.

## 주의

- `.dwg`만 있으면 ODA File Converter로 DXF 변환
- 건축 도면은 대부분 **mm 단위** (도면 폭이 40000 같으면 mm)
- 치수선·문자·해치·가구 레이어는 제외해야 함
- 5층만 필요하면 CAD에서 해당 부분만 잘라 별도 DXF로 저장
